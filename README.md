# Cyber Solutions Homepage

Welcome to the **Cyber Solutions Homepage**, a modern, highly interactive corporate website designed for a Saudi technology company specializing in industrial automation, cybersecurity, and digital transformation.

## 🚀 Overview

The Cyber Solutions website is built using **Next.js 14**, styled with **Tailwind CSS**, and brought to life with **GSAP (GreenSock Animation Platform)**. 
The design emphasizes a dark, modern aesthetic (Navy and Neon Blue) mixed with professional industrial undertones, perfectly suited for the technology and mission-critical infrastructure sector.

## ✨ Features

- **Modern UI/UX**: A dark-themed, glassmorphic design language.
- **Advanced Animations**: Scroll-triggered animations, floating elements, and seamless page transitions powered by GSAP.
- **Fully Responsive**: Optimized for all devices (Mobile, Tablet, Desktop).
- **Arabic-First Typography**: Configured globally with **IBM Plex Sans Arabic** for beautiful bilingual support.
- **Component-Driven Architecture**: Clean, modular Next.js components for easy maintenance.

## 🛠️ Tech Stack

- **Framework:** [Next.js (App Router)](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [GSAP](https://gsap.com/)
- **Icons:** [FontAwesome](https://fontawesome.com/)
- **Fonts:** Google Fonts (IBM Plex Sans Arabic)

## 📦 Getting Started

First, install the dependencies:

```bash
npm install
# or
yarn install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📂 Project Structure

- `/app`: Next.js App Router pages (Home, About, Solutions, Projects, Careers, Contact).
- `/components`: Reusable UI components (Navbar, Footer, AnimatedSection, GSAPWrapper).
- `/public`: Static assets (Images, Icons).
